# 数据周报 Skill

## 统计口径（钉死，不得自行更改）

- **周定义**：自然周，周一 ~ 周日。本周 = 当前系统日期所在自然周（周一 00:00 起、周日 24:00 止），上周 = 本周紧邻的前一个自然周。
- **周期锚点**：以当前系统日期推算周期。**禁止**用 `MAX(sale_date)` 等数据极值当锚点（库中可能含未来日期，会算出含未来数据的"本周"）。
- **环比公式**：`环比 = (本周值 - 上周值) / 上周值`，以百分比表示（如 +15%、-3%、0%）。
- **覆盖不足**：数据不满足整周（缺数、部分日期无数据）时，必须在报告"统计周期"处注明实际覆盖范围，不得静默当作整周。

## 使用流程

1. 用 `query_data` 查询数据（demo 库表 `sales`：sale_date/city/category/amount）。
2. 至少查询：本周总销售额、上周总销售额、环比；分品类汇总；Top 城市。
3. 把算好的指标交给 `weekly-report.render_report` 渲染。
4. 最终回答 = 渲染出的 markdown 周报全文。
